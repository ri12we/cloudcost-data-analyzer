# Cloud Cost Data Analyzer

A Python data analysis project that analyzes cloud spending and visualizes costs by service and month.

## Project Overview

This project uses Python and pandas to analyze cloud cost data from a CSV file. It calculates spending by cloud service and month and creates visualizations to make the cost trends easier to understand.

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV data

## Features

- Analyze cloud spending data
- Calculate total cost by service
- Calculate monthly cloud spending
- Create cost-by-service visualizations
- Create monthly spending trend visualizations
- Export charts as PNG files

## Project Files

- `cloud_cost_analyzer.py` — Main Python analysis script
- `cloud_costs.csv` — Cloud cost dataset
- `cost_by_service.png` — Cost visualization by service
- `monthly_cloud_cost.png` — Monthly cloud spending visualization
- `INTERVIEW_NOTES.md` — Project notes
